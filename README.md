# C 语言练习代码存档（c-exercises）

## 入门与基础函数

- `hello.c` / `1st.c` — Hello World，第一个 C 程序
- `compare.c` — 函数练习：返回两数中的较大值
- `avg.c` — 函数练习：求数组平均值
- `n^k.c` — 递归求 n 的 k 次方
- `GCD.c` / `LCM.c` — 最大公约数 / 最小公倍数

## OJ 与课内题目

- `1001.c` — 简易计算器（连续四则运算，输入 = 输出结果）
- `1002.c` — 三天打渔两天晒网（日期推算）
- `hanoi.c` — 汉诺塔（递归）
- `twin_primes.c` — 孪生素数
- `amicable_numbers.c` — 亲密数
- `weekday_lookup.c` — 星期表查找

## 数组、矩阵与排序

- `transpose.c` — 矩阵转置
- `array_interleave_dedup.c` — 数组分组、交错合并与去重
- `BubbleSort.c` — 冒泡排序
- `InsertionSort.c` — 直接插入排序（输出每趟结果）
- `SelectionSort.c` — 简单选择排序（输出每趟最小值位置）

## 字符串与指针

- `wordcounter.c` — 单词统计器（统计不同单词数，大小写不敏感）
- `caesar_secret.c` — 凯撒加密（字母后移一位）
- `bignumberadd.c` — 大数相加（20\~50 位整数，一维数组逐位相加）
- `traintickets.c` — 铁路购票座位分配

## 结构体

- `struct_teacher_register.c` — 教师登记表类型定义（嵌套结构体）
- `struct_oldest_of_5.c` — 五人中找最年长者

## 编译环境

`gcc -Wall -Wextra -std=c99`
